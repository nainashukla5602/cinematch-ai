# CineMatch AI 

CineMatch AI is a professional movie recommendation web application that suggests movies based on the genres selected by the user. The project is designed with a modern responsive interface and visually appealing movie cards with posters and ratings.

# Features

* Genre-based movie recommendations
* Multiple genres available:

  * Action
  * Comedy
  * Romance
  * Sci-Fi
  * Horror
  * Thriller
  * Adventure
* Movie posters displayed on each card
* Ratings shown for every movie
* Responsive design for mobile, tablet, and desktop
* Professional modern UI
* Fast and lightweight performance

# Technologies Used

* HTML5
* CSS
* JavaScript
